Adaptive mode advances through completed chunks 0-5, with frames 2, 4, 6, and 8 holding the latest completed adaptive chunk because adaptive has fewer completed chunks than the fixed 64-packet presentation intervals.

Left-to-right filling would only be expected if packet/chunk order corresponded monotonically to increasing tick positions, which is not guaranteed.
5. The GIF is safe to use as the primary presentation demo, with the caption caveat that it is cumulative by actual replay chunks, not a left-to-right progress mask.
