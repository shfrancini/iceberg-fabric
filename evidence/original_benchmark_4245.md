## Benchmark Plot Semantics

- Pivot construction: `df.groupby(['wire_id', 'tick'])['adc_value'].max().unstack(fill_value=0)`, reindexed to all ticks and sorted by `wire_id` descending.
- Pivot shape: `[200, 2048]` (`wire_id` x `tick`).
- Plotted tick range: `0` to `2046`. The CSV includes tick `2047`, but the original cells use `np.arange(min_t, max_t)` and `values[0:max_t]`, so tick `2047` is not plotted.
- Heatmap wire order: `top-to-bottom/display rows follow pivot order 199 down to 0`.
- Heatmap ADC treatment: per-wire median pedestal subtraction, `data_subtracted = data_array - median(data_array, axis=1)`, with Plotly color limits `zmin=-20`, `zmax=50`, colorscale `Thermal`.
- Ridgeline wire range/order: `bottom-to-top/display baselines use 0 up to 199`.
- Ridgeline ADC treatment: the visible y trace is scaled ADC deviation, `(raw_values - mean(raw_values)) * 0.01 + baseline`. Raw ADC is carried only in the original Plotly hover `customdata`; the static PNG cannot show hover values.
- Ridgeline scaling/offset: `signal_gain=0.01`, `step=1.0`, `baseline=i*step`.
- Ridgeline y-axis: tick labels are true `wire_id` values. The plotted coordinate is display order/baseline; for event 4245 the wire IDs are contiguous 0-199, so baseline positions numerically match the wire IDs.
